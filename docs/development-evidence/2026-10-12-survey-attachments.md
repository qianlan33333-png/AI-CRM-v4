## 行为与边界

Survey 保留答案、核销和附件关联；Media 只通过 PrivateImageStorage Port 加入同一 PostgreSQL UoW。图片接收、2MB 严格边界及真实解码在事务前完成。请求临时文件结束即释放，无预上传、引用恢复、过期队列或后台清理中心。兑换码原文只在加密码库；答卷与外推使用验证/上传标记。

无图保持 JSON（application/json），含图为原路径 multipart；拒绝简单表单/文本冒充 JSON 和跨源 multipart。含图路由及前端 120 秒，原 JSON 保持 15 秒，未扩大全局服务器等待。

后台原问卷列表增加“查看答卷”，核销记录可打开对应答卷；缩略图及链接均经过原答卷管理员权限。CSV 增加附件列，含题目、文件名和需要后台登录的查看链接；不输出原码、Media ref、图片字节或公开 URL。

## 本机验收

- Survey app/domain/http 小包整包测试；Media domain 的 PNG/JPEG/GIF 真解码及伪造/损坏输入用例。
- PostgreSQL race：附件成功、同 key 原内容重放、内容变更冲突、字段/版本范围、两个合法附件、严格大小边界、事务失败/并发抢码，以及没有兑换码时的可选 JSON/有图提交。
- 真实 PG 在提交后动作接受处注入失败：事务内已见图片、submission_created 审计及 Outbox；回滚后答卷、图片、blob、核销、对应审计/Outbox 均为零。
- 相关既有客户 claim 重放、身份拆分收据保护、版本竞争、兑换码导入及一次性核销合同保持通过。
- Outbound 的新类型序列化只提供“兑换码已验证”“已上传图片”；不发送原码或私有地址。
- 前端合同覆盖两种 H5 的必填、大小、页内预览、替换/移除、失败原 key 重试、刷新/授权后重选，以及运营配置、列表桥接与现有恢复合同。
- `TestPostgreSQLSurveyAttachmentChromiumJourney` 使用真实 Chromium、真实 Survey/Media PostgreSQL Owner 与既有 OAuth 合成边界，验证两种模式；运营 Excel 追加导入、前导零、重复行读回、编辑器配置、无效码弹窗保留图片、成功后 1 答卷/1 图片/1 核销、私有读回、后台缩略图和 CSV。
- OpenAPI 508 路径与路由合同有效；API 生成类型和内容绑定/锁从真实 V4 API commit 更新。

对应命令及具名用例在 `docs/release-checks.json`。最后候选提交后按准确 head/tree 复验并另存执行日志，未执行、skip 或环境缺失不计通过。浏览器构建与旅程串行执行。最终复验额外发现原后台壳的延迟渲染可覆盖运营配置；已保护已读取的 Owner 节点及未保存输入，并增加晚渲染覆盖合同。浏览器合成边界补齐既有日志读取路由，避免缺失路由造成无关壳错误。
