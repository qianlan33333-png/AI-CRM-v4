# V4 开发入口

开始或恢复先读当前 V4 `AGENTS.md`、`docs/development-before-start.md`，再用 [核心开发 skill](../aicrm-v3-development/SKILL.md)。唯一源码目录是 `/Users/qianlan/Downloads/新CRM/AI-CRM-v4`；独立 codex worktree 从国内 main 或工作台累计 HEAD 开始。

一个能力只做一次业务流程、GitHub/市场参考、复用判断和简短父 PRD。已授权相关修复记录差异即可。先写 OneID、持久化、外部效果分类；UI 编码前使用 Product Design，见 [前端 skill](../aicrm-v3-frontend-consistency/SKILL.md)。

交付使用 `dev_preflight prepare`、准确 diff 的直接消费者清单、相关结果和机器生成的 handoff；命令见 [开发入口](../../docs/development-before-start.md)。推送国内准确 ref 后重读工作台路由并实际投递，不只留下等待文字。开发者不安装共享预发/生产，发布者使用 [发布 skill](../aicrm-v4-release/SKILL.md)。
